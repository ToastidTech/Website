# Toastid Tech Website SEO & Accessibility Audit

Date: 2026-09-05
Repository: ToastidTech/Website

## Audit scope

Reviewed the public HTML pages, navigation structure, metadata, sitemap, robots.txt, manifest, image references, client-side behavior, accessibility controls, and the Resources/Blog content structure.

## Findings

### SEO strengths

- Descriptive page titles and meta descriptions are present on the primary pages.
- Canonical metadata already existed on the homepage, Resources page, and comparison article.
- `robots.txt` permits crawling while excluding private/staging paths.
- `sitemap.xml` includes the main public pages and the comparison article.
- A keyword strategy exists in `seo/toastid_tech_keywords.csv`.
- Resources content targets PWA development, business audits, automation, AI strategy, and related long-tail search intent.
- The site uses semantic headings, descriptive image alt text, and real text content rather than relying on graphics for core information.
- The web app manifest and 192px/512px icons are present.

### SEO gaps addressed

- Added a centralized structured SEO/data layer through `assets/site.js` for every public page.
- Added canonical URLs for pages that lacked them.
- Added `robots` index/follow directives and large-image preview permission.
- Added Open Graph title, description, URL, site name, and image metadata.
- Added Twitter card metadata.
- Added author metadata.
- Added Schema.org JSON-LD for Organization and WebSite entities.
- Added BreadcrumbList data for crawl context.
- Added ItemList structured data for the Products & Services catalog.
- Added Service structured data for consulting, audits, automation, and PWA development.
- Added Blog/Article structured data where appropriate.
- Added AboutPage and ContactPage structured data.
- Refreshed sitemap `lastmod` dates to 2026-09-05.

### Accessibility gaps addressed

- Added a keyboard-accessible Skip to main content link.
- Added visible `:focus-visible` styling with a strong focus indicator.
- Added `aria-controls`, `aria-expanded`, and meaningful labels to the mobile navigation button.
- Marked decorative background/canvas effects as hidden from assistive technology.
- Added reduced-motion handling for CSS animations and transitions in addition to the existing JavaScript motion check.
- Exposed Resources filter controls as tabs with `aria-selected` and keyboard focus state.
- Added `autocomplete` hints to contact form name/email fields.
- Converted visible email and telephone contact details into keyboard/touch-friendly `mailto:` and `tel:` links.
- Preserved real text content and descriptive image alt text.

### Performance/accessibility observations

- The site has substantial visual effects. They are now suppressed more comprehensively when users request reduced motion.
- Several logo assets are large. Existing fixed-size logo containers reduce layout shift, but future image compression/WebP conversion would further improve Core Web Vitals.
- A full browser Lighthouse run was not available from the repository connector, so this audit is source-level rather than a claim of a measured Lighthouse score.

## Search strategy

The current SEO direction prioritizes intent-driven phrases such as AI consulting, business technology audits, business process automation, Progressive Web App development, AI solutions for small business, workflow automation, and custom AI/web app development. The keyword CSV is treated as a content strategy, not as a reliance on the obsolete `meta keywords` ranking signal.

## Crawl architecture

Primary crawl path:

Home → Products & Services → Resources & Blog → About → Contact

Supporting content:

Resources/Blog → individual article anchors → Contact

Comparison article → Resources → Products → Contact

Sitemap and robots.txt remain available at the domain root.

## Remaining opportunities

1. Split the long Resources hub into individual article URLs for stronger long-tail indexing and richer Article schema.
2. Add unique OG images for major pages and articles rather than using the brand shield everywhere.
3. Compress large logo/photo assets and serve modern formats where practical.
4. Add Search Console validation/coverage monitoring after deployment so indexing changes can be measured rather than guessed.
5. Continue publishing focused, genuinely useful articles around the keyword clusters already defined in the SEO strategy.
